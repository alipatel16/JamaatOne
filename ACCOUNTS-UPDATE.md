# JamaatOne Accounts Update

- Added admin/committee-only Payments, Day Book, and Customer Ledgers views.
- Added payment types: Misaq Lagat, Shehra Lagat, Donation (Hub), and Madrasa Fee.
- Donation types: Madrasa Hub, Kabrastan Hub, Masjid Hub, Jumaat Hub.
- Madrasa fee types: Admission Fee, Monthly Fee, Exam Fee.
- Added searchable member picker for payment entry.
- Added payment search and from/to date filters.
- Added debit/credit daily entries and balance summary.
- Added searchable customer ledgers and ledger information inside user details.
